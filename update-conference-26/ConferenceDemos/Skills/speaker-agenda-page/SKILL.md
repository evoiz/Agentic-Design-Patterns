# Speaker agenda page

Produce ONE file, `agenda.html`, in the sandbox with the file write tool. It must open offline in any browser.

## Workflow

1. Record todos first: profile, choose agenda, check agenda, (research links when web search is enabled), write page, verify file.
2. Call `GetSpeakerProfile`, then `ListSessions` for the requested day.
3. Choose the agenda (the speaker's own talk included) and call `CheckAgenda` with the ids. Repeat until every goal passes.
4. Call `GetSession` for each chosen session to get its exact title, abstract, and URL.
5. Only when web search is available: find 2-3 current, reputable links matching the interests (prefer official docs such as learn.microsoft.com or github.com) and optionally one practical Prague tip. Never invent URLs.
6. Read `references/design.md` with the skill resource tool, then write `agenda.html`.
7. List or read the file back to verify it was saved, then mark the remaining todos complete.

## Hard rules (checked by code after you finish)

- Every chosen session is rendered as `<article class="session" data-session-id="ID">` with its EXACT schedule title.
- The page shows the speaker's full name and the exact title of their own talk.
- Use the profile `PhotoFile` as `<img src="PhotoFile">` when it is not null; otherwise render an initials avatar with CSS. Never reference any other image.
- Self-contained: inline `<style>` only. No `<script>`, no `<iframe>`, no external fonts or stylesheets, no `@import`.
- Links: schedule URLs from `GetSession`, the profile repository, and (web search only) links you actually found.
- Keep it under 300 KB. Valid HTML5 with `<!doctype html>` and `</html>`.
- Prose (tagline, Why lines) may only state schedule facts visible in the timeline; do not describe free time or breaks you did not render.

## Required sections (in order)

1. `header.hero` - avatar/photo, name, role, conference + day + date, one-line summary of the day.
2. `section#my-talk` - highlighted card for the speaker's own talk: time, room, title, 1-2 sentence abstract summary, link.
3. `section#timeline` - the day in time order: chosen sessions (time, room, tracks as chips, title, speaker, one-line "why", link) interleaved with breaks (lunch, coffee) and the kept-free preparation slot.
4. `section#goals` - small checklist of the agenda goals that `CheckAgenda` confirmed.
5. `section#further-reading` - ONLY when web search is enabled: 2-3 links with one sentence each.
6. `footer` - "Generated by a Microsoft Agent Framework HarnessAgent from the Update Conference Prague 2026 schedule", the generation date, and the repository link.
